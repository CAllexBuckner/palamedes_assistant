# Palamedes Assistant
The goal of this project is to create a personal assistant using a series of LLM models for a "magic mirror" smart screen I'll be putting in my office...eventually.

The backbone of this model is based off of benpoly's [Building a Robot that Hunts AI Glasses](https://www.youtube.com/watch?v=kd_8QFCSFAE&t=561s), without the visual models input (for now at least). 

## Workflow
- [ViolaWake](https://violawake.com/docs/) for custom wake word training and implimentation
- [Whisper](https://github.com/openai/whisper) for general speach recognition and transcription
